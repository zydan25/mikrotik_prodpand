# 🚀 MikroTik PPPoE Broadband Manager (منظومة إدارة واشتراكات برودباند مايكروتك)

منظومة ويب متكاملة، خفيفة، وسريعة مخصصة لإدارة اشتراكات برودباند **PPPoE** لشبكات وأجهزة **MikroTik RouterOS** مع المراقبة اللحظية للاستهلاك وسندات وحسابات الموظفين.

---

## ✨ المميزات الرئيسية

### 1. 👥 إدارة كاملة لاشتراكات PPPoE (دون بطء)
- **مربوطة باليوزرات مباشرة:** لا حاجة لتعقيد جداول العملاء المنفصلة؛ يتم ربط بيانات المشترك (الاسم، الهاتف، الملاحظات) مباشرة باسم مستخدم PPPoE.
- **تجديد فوري لمشترك سابق:** إمكانية البحث عن أي مستخدم قديم واختياره لتعبئة بياناته وتجديد اشتراكه وتمديد تاريخه فوراً.
- **إضافة وتعديل وحذف وتعطيل/تفعيل:** مع مربعات حوار تأكيد (Confirm Modals) ومؤشرات تحميل متحركة (Spinners) لجميع العمليات.

### 2. ⚡ مراقبة الاستهلاك وحالة الاتصال اللحظية (Live Traffic & Uptime)
- **مؤشر الاتصال المباشر:** يوضح إذا كان المشترك متصلاً الآن على الراوتر (🟢 Online) مع مدة الجلسة الحية (**Uptime**) والـ IP المسحوب وعنوان MAC Lock.
- **حجم البيانات المستهلكة بدقة:**
  - ⬇️ التحميل المباشر (**Download / TX Bytes**).
  - ⬆️ الرفع المباشر (**Upload / RX Bytes**).
  - إجمالي البيانات المنقولة (بالجيجابايت أو الميجابايت).
- **العداد الزمني للانتهاء:** تاريخ ووقت بدء الاشتراك وتاريخ الانتهاء مع عداد للأيام المتبقية أو المنتهية.

### 3. 📦 إدارة باقات وفئات الخدمة (PPPoE Profiles & Quotas)
- **فئات الخدمة:** تصنيف الباقات تلقائياً (منزلي، سرعات فائقة / VIP، ألعاب، VPN...).
- **سعة البيانات (GB Quota):** إمكانية تحديد حجم أقصى للباقة (مثلاً 50GB أو مفتوح Unlimited).
- **مدة الصلاحية:** تحديد مدة الباقة بالأيام (30 يوم، 60 يوم...).
- **مزامنة بنقرة واحدة:** استيراد كافة باقات الراوتر ومزامنتها بضغطة زر.

### 4. 🧾 سندات وحسابات الموظفين والتسويات (Employee Balances & Settlements)
- **تتبع عهد ومستحقات الموظفين:** معرفة المبالغ المحصلة في ذمة كل موظف بدقة.
- **إضافة سند قبض / تسوية:** تسجيل دفعات الاستلام من الموظفين مع أرقام إيصالات وملاحظات.
- **تصفير الحسابات:** تصفير شامل بضغطة زر وتأكيد.
- **تقرير شهري مفصل:** فرز حسب الشهر والسنة لكافة العمليات المالية للموظف، مع سندات قابلة للطباعة المباشرة.

### 5. 📱 واجهة عصرية متجاوبة بالكامل (Desktop & Mobile)
- **عنصر اختيار تفاعلي موحد (Searchable Dropdown):** شريط بحث علوي مع فلترة لحظية وخلفية بيضاء ونصوص سوداء مقروءة لكافة القوائم المنسدلة في النظام.
- **بطاقات موبايل كاملة العرض:** في الهواتف، تتحول الجداول تلقائياً إلى بطاقات عصرية بعرض الشاشة (`100%`) تضم شبكات إحصائيات مصغرة وأزرار لمسية كبيرة وسهلة الاستخدام.

## 🛠️ متطلبات التشغيل والتثبيت

### 1. تثبيت الحزم المطلوبة
```bash
pip install -r requirements.txt
```

### 2. تشغيل التطبيق
```bash
python app.py
```

- يعمل التطبيق افتراضياً على: `http://127.0.0.1:5000`
- **بيانات تسجيل الدخول الافتراضية:**
  - **اسم المستخدم:** `admin`
  - **كلمة المرور:** `admin123`

---

## ⚙️ ربط جهاز MikroTik
1. ادخل إلى **أجهزة MikroTik** (`/admin/devices`) -> **إضافة جهاز**.
2. أدخل IP الراوتر أو رابط الـ DDNS (مثل `your-router.sn.mynetname.net`).
3. أدخل منفذ الـ API (الافتراضي: `8728` أو المنفذ المخصص لديك).
4. أدخل اسم مستخدم وكلمة مرور الراوتر التي تملك صلاحية `api` و `write`.
5. اضغط **فحص الاتصال** ثم **حفظ**.
6. اضغط **"مزامنة الباقات"** و **"استيراد المشتركين"** لجلب كافة بياناتك القائمة في ثوانٍ معدودة!
